## Release gate handoff

The P4 harness prints `EVIDENCE_BUNDLE=<absolute-bundle-directory>`. The release workflow must
pass that directory explicitly:

```bash
uv run python scripts/release_gate.py validate --p4-evidence "$EVIDENCE_BUNDLE"
uv run python scripts/release_gate.py prepare --p4-evidence "$EVIDENCE_BUNDLE"
```

The `prepare` command copies the validated P4 bundle into the release-preparation directory and
binds it through `SHA256SUMS`. Missing, dirty, cross-SHA, cross-Chart, `NOT_RUN`, failed-cleanup,
or checksum-drifted evidence stops preparation.
